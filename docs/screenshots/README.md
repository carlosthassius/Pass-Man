# Capturas para o repositório

Use somente dados fictícios nas imagens.

Arquivos sugeridos:

- `unlock.png`: tela de desbloqueio com o fluxo de primeiro acesso.
- `vault-dark.png`: cofre no tema escuro, com cards fictícios.
- `vault-light.png`: cofre no tema claro e menu expandido.
- `recovery.gif`: primeiro acesso, download da chave de recuperação e recuperação com uma nova chave.

Para criar as imagens, execute o app por localhost, use um perfil limpo do navegador e oculte nomes, e-mails, logins e senhas reais. A largura sugerida é 1440 px para PNG e 1280 px para GIF.
